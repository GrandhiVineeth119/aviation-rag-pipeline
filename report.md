# RAG Pipeline — Evaluation Report

> This report is auto-generated by `evaluate.py`. Run the evaluation to populate it:
> ```bash
> python evaluate.py --out report.md
> ```

## How to generate this report

1. Ensure documents are ingested: `python ingest.py`
2. Run evaluation: `python evaluate.py --out report.md --json eval_results.json`
3. The report will contain:
   - Aggregate metrics (hit-rate, faithfulness, hallucination rate, citation accuracy, refusal accuracy)
   - Per-question breakdown
   - 5 best and 5 worst answers with explanations
   - Out-of-scope refusal analysis
